## Candidate Agency OS lessons

Do not promote these into the frozen V1 baseline until demo review is complete:

- full-page screenshots can misrepresent pinned/reveal-heavy pages; capture meaningful scroll states plus a reduced-motion/static version;
- animated copy needs a readability floor instead of being faded purely for drama;
- hiding desktop navigation requires an explicit mobile navigation replacement;
- experimental CSS visual treatments need safe fallbacks;
- visual QA should capture browser console/page errors, not screenshots alone;
- a reproducible package-manager lockfile should be a project scaffold gate;
- automated accessibility/performance/cross-browser checks should be considered for the next QA layer.
