# VELORNE / Study 01 — asset pipeline

Direction: Obsidian Atelier. Local Blender rendering, with one original fictional assembly. No paid assets or external product imagery.

## Editable source

- `assets/source/velorne-study-01.blend`
- `scripts/render/watch.py` regenerates geometry, materials, lights and cameras.

Proposed appearance: graphite dial, faceted hands, applied markers, fluted crown, brushed-metal case with polished bevels, clear crystal and articulated bracelet. Scene coordinates are arbitrary units. There are no claimed real dimensions, material grades, manufacturing origins or performance specifications. The movement is illustrative, not a validated caliber. The crystal uses a non-refractive transparent coating with a Fresnel-weighted reflection to avoid doubled dial lettering. This is a presentation approximation, not a sapphire optical simulation.

## Delivered media contract

All web images live in `public/media/velorne/`:

- `hero.webp`, `three-quarter.webp`: studio portrait.
- `front.webp`, `rear.webp`: product gallery.
- `macro-case.webp`, `macro-dial.webp`, `macro-movement.webp`: close observation.
- `anatomy-overview.webp`: exploded portrait; default for reduced motion and unavailable animation.
- `*-640.webp`: responsive still-image derivatives.
- `sequence/000.webp` through `059.webp`: 800 × 800 rendered animation frames.
- `sequence-mobile/000.webp` through `059.webp`: 500 × 500 mobile derivatives.

Hero and three-quarter are the same shot intentionally reused. The client chooses responsive sizes and defers nonhero images. No browser requests missing files; the build-time manifest enables animation only when every frame exists.

## Motion implementation

The sequence is rendered from actual 3D separation and camera choreography. It replaces the earlier cutout-layer prototype. Crystal, hands, indices, dial, movement, caseback and crown move relative to the case and bracelet. Scroll reverses the film naturally.

The original three templates use GSAP to map native scroll to frame progress. Desktop pins the stage. Mobile uses a shorter native sticky image region. A maximum of ten decoded frames and two fetches in flight limits runtime memory. Frames render only near the section and while the document is visible. Reduced-motion and data-saving paths retain the static exploded portrait and semantic component notes.

The Cinematic template uses a native requestAnimationFrame timeline with 95 ms damping, adjacent-frame blending, subtle camera drift and coordinated background/copy transitions. It retains up to 14 decoded images plus the compressed sequence, with mobile frames at 500 px. A build-time hash of the desktop sequence versions both sequence URLs, preventing stale force-cached animation frames after a render replacement.

## Reproduction

From the repository root, with local tools installed:

```sh
source .tools/env.sh
"$BLENDER_BIN" -b -t 4 --python scripts/render/watch.py -- --mode proof --size 800 --samples 96 --output artifacts/render-proof
"$BLENDER_BIN" -b -t 4 --python scripts/render/watch.py -- --mode stills --size 1400 --samples 48
"$BLENDER_BIN" -b -t 4 --python scripts/render/watch.py -- --mode sequence --size 800 --samples 32
node scripts/optimize-media.mjs
pnpm build
```

To correct one still without rerendering the set, use `--mode stills --shot anatomy-overview` (or another named shot). `--output artifacts/render-candidate` isolates media and the editable scene from published assets; `--resume` skips existing candidate files only when `--output` is set. Use a fresh candidate directory whenever render settings change. Verify reflections, alpha edges, markers, typography, assembly relationships and mobile crops at actual delivery size. Keep noisy lighting tests out of public media. The saved Blender file is assembled; animation poses are generated by the reproducible script.

## Local assembly film and template previews

`assembly-film.mp4` is an 8-second, silent H.264 film encoded from the existing 60 Blender frames. Adjacent-frame blending supplies a 24 fps playback stream; it is not newly rendered 24 fps movement. It is approximately 1.6 MiB and contains no external/reference footage or paid generation.

Reproduce on macOS with the installed Node dependencies and Swift/AVFoundation:

```sh
node scripts/render/prepare-film.mjs
swift -module-cache-path /private/tmp/swift-module-cache scripts/render/assembly-film.swift
```

AVFoundation encoding needs access to the local macOS encoder. The Studio and Atelier film dialogs fetch the video only when opened. Nocturne uses it as a decorative background with a pause control; mobile, reduced-motion and save-data settings start with a still instead. Background playback pauses offscreen and while the tab is hidden.

`public/media/templates/{studio,atelier,nocturne,cinematic}.jpg` are browser screenshots of the actual local templates, created by `scripts/review-templates.mjs` and `scripts/review-cinematic.mjs`. They are comparison-page thumbnails, not new watch imagery. The supplied clips and design collage are references only and are not included in the website.
