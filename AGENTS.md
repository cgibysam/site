# Project AI Instructions

This repository holds CGI by Sam demo websites, one self-contained static site per folder (`patty/`, `inerg/`), plus brand tokens in `tokens/`.

Canonical reusable standards:
- repository: `cgibysam/agency-os`
- branch: `main`
- local checkout: `~/Desktop/CGI` (read the rulebook from here; do not fetch it from GitHub)
- start: `AI-ENTRYPOINT.md`
- primary profile: `03-PROJECT-PROFILES/WEBSITE.md`
- stack: `02-RULES-AND-STANDARDS/HOUSE-WEB-STACK.md` (no build step; house motion module first, vendored GSAP + Lenis only when needed)
- discoverability: `02-RULES-AND-STANDARDS/SEARCH-AND-AI-DISCOVERABILITY.md`

This repository remains authoritative for its sites' implementation and demo-specific decisions. All businesses here are fictional; do not invent real-world claims.

Do not deploy, merge to `main`, or change Cloudflare Pages settings without explicit approval.
